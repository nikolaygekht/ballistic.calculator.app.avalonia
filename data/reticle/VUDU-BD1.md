# VUDU-BD1 — EOTech Vudu X BD1 (SFP, MOA)

The Ballistic Drop reticle from EOTech's **Vudu X** line — not classic Vudu. A wide-open duplex with four
holdover **circles** rather than bars. **Second focal plane.**

## The pattern

- **Open centre** — **20 MOA** across: the heavy posts start **10 MOA** out on all four arms.
- **Centre dot** — **0.25 MOA**, illuminated red.
- **Horizontal reference hashes** at **2 MOA** and **4 MOA** each side.
- **Four holdover circles** below the centre, each **1.0 MOA** across.
- **The stem below centre is broken, not continuous.** It runs from the centre to the **top** of the first
  circle, then from the **bottom** of that circle to the top of the next, and so on, resuming below the last
  circle and running out to the post. The line never crosses a circle — the segments are 0→1.5, 2.5→3.5,
  4.5→5.5, 6.5→7.5 and 8.5→10 MOA, each abutting a circle's edge exactly.

That last point is the detail that makes the reticle read correctly: an unbroken stem through the circles
turns each one into a crossed-out ring instead of an open aiming circle you can see a target through.

The circles are what make it distinctive: an open ring is easier to place over a target at speed than a bar,
and you can see through it.

## The marks

| Below centre | Mark |
|---|---|
| **2 MOA** | circle |
| **4 MOA** | circle |
| **6 MOA** | circle |
| **8 MOA** | circle |

All four printed, and confirmed by the Vudu X manual's own prose: "the circles provide a 2, 4, 6, and 8 MOA
hold over".

## Second focal plane

The subtensions hold at one magnification only. EOTech's Vudu X ships this reticle on the 1-6×24 and the
2-12×40, so **which** magnification depends on the scope — the manual states the reticle specification without
naming a reference power. Treat the values as the maximum-magnification case, as the rest of the SFP files in
this folder do, and check against your own optic.

## Which numbers came from where

The **Vudu X 1-6×24 SFP user manual** p7 — a dimensioned figure. The same reticle appears in the 2-12×40
manual. Note the turret specification sits in the text layer but the reticle dimensions do not, so the figure
was read as a drawing.
