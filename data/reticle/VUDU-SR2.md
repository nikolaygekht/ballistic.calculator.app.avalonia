# VUDU-SR2 — EOTech Vudu SR-2, 7.62 (FFP, milliradian)

A speed ring over a three-rung ballistic ladder, calibrated for 7.62×51. **First focal plane.** One of only
two reticles in this folder whose **load EOTech actually prints on the drawing** — the other is its 5.56
sibling, [SR-3](VUDU-SR3.md).

## The pattern

- **Speed ring** — **2.15 mrad outer diameter**, **0.3 mrad** thick, **closed**, illuminated red. At 1× this
  is the fast close-range aiming feature; at magnification the ladder takes over.
- **Centre dot** — **0.44 mrad (1.5 MOA)**.
- **Reference ticks** on the horizontal at **4 mrad (13.75 MOA)** and **6 mrad (20.63 MOA)** each side. There
  is **no continuous horizontal line** — the ticks stand alone, which is what the drawing shows.
- **Three BDC bars**, **0.07 mrad (0.24 MOA)** thick, numbered 4, 5, 6, joined by a **vertical spine running
  from the "4" bar to the "6" bar** and no further. Nothing connects the ring to the ladder.

## The marks

| Below centre | Range | Numeral |
|---|---|---|
| **2.5 mrad** (8.59 MOA) | 400 yd | 4 |
| **3.7 mrad** (12.72 MOA) | 500 yd | 5 |
| **5.0 mrad** (17.19 MOA) | 600 yd | 6 |

Every one of those six figures is printed — position in mrad, position in MOA, and the yardage. Note the
ranges are in **yards**, unlike most of this folder.

## Calibration

| | |
|---|---|
| Cartridge | **7.62×51mm (M118LR)** |
| Bullet weight | **175 grain** |
| Muzzle velocity | **2550 ft/s** |
| Ballistic coefficient | **0.495** |
| Sight height | **1.5 in** |
| Zero | **not published** — see below |
| Focal plane | first (FFP) |
| Library entry | none shipped — enter the designation load: **175 gr at 2550 ft/s** |

**The mark positions are exact; the load is nominal.** EOTech's ammunition line is a representative load, so
when the application labels these marks from your own trajectory they will not necessarily land on
400/500/600 yd. That is correct behaviour, not an error in the file.

**The zero is not published.** EOTech give bullet, weight, velocity, BC and sight height but no zero
distance — and a zero is needed before any label means anything. With the ladder starting at 400 yd, 100 yd is
the obvious candidate, but it is an inference. Whichever zero puts the labels on 400/500/600 yd is the one to
use; if you establish it, record it here.

## Two values not printed

- **The BDC bars' width.** Their *thickness* is dimensioned (0.07 mrad) but not their length. Drawn **1.0 mrad**
  wide to match the drawing's proportions — cosmetic, and not a subtension you would measure with.
- Nothing else. The ring, dot, ticks and all three bar positions are printed values.
