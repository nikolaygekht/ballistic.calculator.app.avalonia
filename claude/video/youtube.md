# Uploading the episodes to YouTube

Status (2026-11-03): **not set up yet** — this is the agreed plan.
Ready-to-paste text for the channel, the playlist and all ten episodes (title, description with chapters,
tags): **`youtube-metadata.md`**, generated by `build/make_metadata.py` from `demo-script.md` (2026-11-05). No YouTube MCP is connected; uploads go
through the YouTube Data API v3 from a Python script.

## One-time setup (the user)

1. Google Cloud Console → new project (e.g. `bc2-video`).
2. APIs & Services → Library → enable **YouTube Data API v3**.
3. OAuth consent screen: type **External**, publishing status **Testing**, add your own Google account
   as a test user. Scope: `https://www.googleapis.com/auth/youtube.upload` (+ `youtube` for playlists and
   thumbnails, `youtube.force-ssl` is not needed).
4. Credentials → Create OAuth client ID → **Desktop app** → download the JSON.
5. Store it **outside the repo**, e.g. `%USERPROFILE%\.secrets\bc2-youtube\client_secret.json`. The
   refresh token the script writes (`token.json`) goes next to it. Never commit either.
6. Thumbnails need a **verified channel** (phone verification in YouTube Studio), otherwise
   `thumbnails.set` fails.

## The script (Claude writes it: `claude/video/build/upload.py`)

- `pip install --user google-api-python-client google-auth-oauthlib`
- `python upload.py --auth` — one-time browser consent (run it as `! python …` in the Claude session).
- `python upload.py epNN` — uploads `build/epNN/epNN.mp4`:
  - title, description and tags from the episode's **YouTube metadata** block in `demo-script.md`
    (`### Episode descriptions`): the episode text, then its chapter list, then the common end block. Any
    credit paragraph in a description (ep. 6: the PrecisionRifleBlog article link for the pictures used on
    screen) is part of the description and must be uploaded verbatim;
  - `categoryId` 28 (Science & Technology), `defaultLanguage`/`defaultAudioLanguage` `en`,
    `selfDeclaredMadeForKids` false;
  - privacy **private** (see limits) — the user reviews and publishes by hand in Studio;
  - resumable upload (`MediaFileUpload(..., resumable=True)`), so a dropped connection resumes;
  - thumbnail `thumbs/epNN.jpg` (the ad: `thumbs/ad30.jpg`; 1280x720, ~0.1 MB, episodes = their title cards scaled from `cards/out/title-NN.png`, the ad its own; made by `thumbs/make_thumbs.py`) via `thumbnails.set`;
  - adds the video to the series playlist (`playlistItems.insert`, position = episode − 1);
    the playlist id lives in the script config, created once with `playlists.insert` or by hand;
  - writes the returned video id to `build/epNN/youtube.json` (gitignored like other build output) so
    episodes link to each other and a re-run does not upload twice.

## Limits to remember

- **Unverified API projects upload as private only.** Videos uploaded by an app that has not passed
  Google's API audit are locked to private. That suits us: publishing stays a manual, deliberate
  step in Studio.
- **Quota:** default 10 000 units/day; `videos.insert` costs ~1 600, `thumbnails.set` 50,
  `playlistItems.insert` 50 → roughly 6 episodes per day. Eight episodes take two days.
- Uploading is outward-facing: Claude uploads only when asked for a specific episode.
