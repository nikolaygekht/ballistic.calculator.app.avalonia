Written at the end of the 2026-07-29 session. Everything in [`07-28.md`](07-28.md) is closed, so this is
what stands between the current `main` and a first public release.

## State at the end of 2026-07-29

  `TrajectoryCannotBeCalculatedException`, and `MilDotReticle` in milliradians.

## Blockers

1. **Push the seven commits.** Nothing else waits on it, but nothing is backed up either.
2. **Interactive smoke pass on the four Tools dialogs** — Approximate Drag Table from BC Curve and from
   Measured Velocities, Convert Ballistic Coefficient, Hit Probability. `STATUS.md` has flagged this as
   outstanding since each was built; they are the last surface with no hand check. **Nikolay's to do** —

3. **The five stub articles in the manual.** `docs/index.md` lists them as plain entries: the summary view,

   **The last one matters most for a public release**, because the risk notice points at it: a user needs to
   know where the numbers stop being trustworthy.

## Should be fixed before a public build

4. **`data/drg/Lapua/308-lapua n558 11,0g (170gr) naturalis_radar.drg` cannot be opened** — its header has a
   period where a comma belongs (`.007830. .03370`), so `DrgDragTable.Open` throws. A one-character data fix
   beats the entry in `docs/known-problems.md` that currently tells people it is broken. Remove the entry
   when the file is fixed.
5. **`Desktop - Shortcut.lnk`** is untracked in the repo root — delete it, and consider `*.lnk` in
   `.gitignore`.
6. **The hit-probability defaults are judgement calls awaiting review** (`STATUS.md`): range 2 %, wind 30 %,
   MV 0.7 %, and a 1 MOA group. They ship as the first numbers a user sees, so they set expectations.

## Worth considering, not blocking

7. **A 16 in XM855 entry.** The Specter ladder is the same bullet as `XM855 Ammo` at 2800 ft/s rather than
   3050; `data/reticle/README.md` currently says to change the muzzle velocity by hand.
8. **F-2 is guarded, not fixed.** A calculation failure reports cleanly instead of crashing, which is
   enough — but the guard is a net, not validation.
9. **The `.reticle` files are inconsistent about line endings.** `PSO-1` and `VCOG16-300BLK` are LF, the
   rest CRLF. Cosmetic; only worth a pass if it bothers you in diffs.

## Two things learned on 2026-07-29, worth not relearning

- **Ask which platform before treating a visual oddity as a defect.** Two rounds of work went into a
  WSLg-only symptom that is correct on real Ubuntu 24.04 and on Windows — and reproduces in a twelve-line
  native Tk program, so it is not even Avalonia's. Written up in
  [`wslg-modal-dialogs.md`](wslg-modal-dialogs.md); do not re-investigate.
- **UI testing is Nikolay's, not Claude's.** Driving the Avalonia apps from WSL cost a PowerShell
  screenshot harness, `SendKeys` that never reached the focused control, a window restored half off-screen,
  and a "startup asterisk" that never reproduced. He found three real defects by hand in that time. Claude
  writes the headless tests and says what to look at.
